# 🌾 농부 키우기 (Raising a Farmer)

휴대폰 세로 화면용 키우기(방치형) 웹 게임입니다. 설치·빌드 없이 `index.html` 하나로 동작합니다.

## 게임 방법
- **밭을 터치**: 작물이 다 자라면(`!` 표시) 터치해서 수확 → 🪙코인 + 경험치
- **업그레이드**: 코인으로 구매
  - 🌱 씨앗 등급: 상추 → 당근 → 감자 → … → 황금 사과 (수확 가치·경험치 증가)
  - 🧪 비료: 성장 속도 / 🧺 수확량: 코인 배수 / 🟫 밭 확장: 최대 8칸
  - 🧑‍🌾 일꾼 고용: 다 자란 작물을 자동 수확 (방치 수입)
  - 🍀 행운의 손: 확률로 3배 대박
- **📺 광고 보기**: 2분간 작물 성장 2배 (최대 10분까지 누적)
- **캐릭터 진화**: 업그레이드를 많이 할수록 밀짚모자 → 멜빵바지 → 장갑/장화 → 괭이 → 황금 장비의 전설의 농부로 진화
- **자동 저장**: 브라우저(localStorage)에 저장되어 다시 들어오면 이어집니다. 접속하지 않은 동안 일꾼이 번 코인(최대 8시간, 효율 50%)도 받아요.

## 파일 구조
| 파일 | 설명 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 스타일 (모바일 세로 전용) |
| `game.js` | 게임 로직 / 저장 / 캐릭터 진화 그리기 |
| `assets/farmer.png` | 기본 캐릭터 (배경 제거본) |

## 밸런스 조정
`game.js` 상단의 `CROPS`(작물 성장시간·가치·경험치), `UPGS`(업그레이드 비용 공식), `STAGES`(진화 단계 기준)를 수정하세요.

## 실제 광고 연결
지금은 `AD_TEST_MODE = true`로 5초짜리 가짜 광고가 재생됩니다.
실제 광고(예: Google AdSense for Games / AdMob 웹 SDK)를 쓰려면 `game.js`의 `showRewardedAd()`가
**광고를 끝까지 봤을 때 `true`로 resolve되는 Promise**를 반환하도록 교체하고 `AD_TEST_MODE`를 `false`로 바꾸면 됩니다.

## GitHub Pages 배포
1. 이 브랜치를 `main`에 병합합니다 (GitHub에서 Pull Request → Merge).
2. 저장소 **Settings → Pages** 로 이동합니다.
3. **Build and deployment → Source: Deploy from a branch** 선택.
4. **Branch: `main` / 폴더: `/ (root)`** 선택 후 **Save**.
5. 1~2분 뒤 `https://<GitHub아이디>.github.io/Raising-a-Farmer/` 로 접속됩니다.
6. 휴대폰 브라우저에서 접속 → 공유/메뉴에서 **홈 화면에 추가**하면 앱처럼 실행할 수 있어요.

> 진행 상황은 주소(도메인)별로 브라우저에 저장됩니다. 다른 브라우저/기기와는 공유되지 않고, 브라우저 데이터를 지우면 초기화돼요.
